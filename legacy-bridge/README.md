</div>

All commands continue to work seamlessly for backwards compatibility, but we strongly encourage you to migrate to `chimeraguard`:

```bash
# Global Install:
npm install -g chimeraguard

# Or Instant Execution:
npx chimeraguard audit https://your-website.com
npx chimeraguard origin https://your-website.com
```
